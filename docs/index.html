Introducció teòrica

Què és Git?

Git és un sistema de control de versions que registra els canvis dels arxius i permet treballar en branques, crear commits i recuperar versions anteriors.

Què és Git Flow?

Git Flow és una metodologia que organitza les branques del projecte: main per a producció, develop per al desenvolupament, feature per a noves funcionalitats, release per a versions estables i hotfix per a correccions.

Per què l'hem utilitzat?

Per simular el treball de tres programadors, separar funcionalitats, integrar-les de manera ordenada i preparar la primera versió estable del projecte.
